# COOKED live benchmark — Qwen 2.5 3B output audit (November 16, 2026)

**Source run:** [GitHub Actions run #43845735060](https://github.com/shaikhabdullahwaseem17-byte/COOKED/actions/runs/43845735060)  
**Model:** `qwen2.5:3b`  
**Run result:** 6 of 8 outputs generated.  
**Scope:** Eight fixed English-language diagnostic situations, four styles. This is a small engineering diagnostic, not a representative sample of Instagram comments.

## Editorial verdict

**The default model did not meet COOKED's target.** Six responses were returned, but the set contains weak punchlines, invented context, a sexualized clothing reference, and two complete generation failures. The existence of an output is not evidence that the output is funny.

This is one editorial review, not an independent human panel. No 4/5 quality claim is supported by this run.

## What the run establishes

1. The previous default model generated only 6/8 cases.
2. The selected outputs were not consistently specific, original, or natural enough to ship.
3. A prompt-only improvement cannot be treated as a success without inspecting the outputs.
4. The output-safety filter missed a suggestive clothing euphemism. A regression test and a broader all-ages pattern guard have since been added.
5. The number-consistency check was also refined so an idiomatic phrase such as “One sunrise” is not automatically treated as a fabricated numeric count. This is a targeted regression fix; this report does not prove that this was the sole cause of the Desi case failure.

## Decision

Keep `qwen2.5:3b` as a lightweight compatibility setting only; do not market it as release-quality humor. The current live challenger is `gemma4:12b`. It must pass the fixed-case run and receive independent blind human review before any quality claim or default-model change.

The GitHub Actions artifact includes the raw benchmark report and a blank human-review worksheet. For external validation, at least two reviewers should score the same outputs independently while blind to the model identity. Keep their individual ratings and safety judgements.

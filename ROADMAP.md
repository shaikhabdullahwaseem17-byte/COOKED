# Roadmap

## Included in this release
- English-only output and API
- Ollama local inference
- OpenAI-compatible inference adapter
- Three-candidate generation with editor selection and heuristic fallback
- Four humor styles: Instagram, dry, Desi (English-language South Asian humor), and absurd
- Web UI, JSON API, tests and live English benchmark

## Planned
- Stronger English humor quality evaluation with human review
- Anti-cliche and duplicate-output improvements
- Optional community example packs with provenance
- Docker deployment and hosted public demo

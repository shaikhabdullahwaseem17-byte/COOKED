# Roadmap

## Included in this release
- Ollama local inference
- OpenAI-compatible inference adapter
- Three-candidate generation with heuristic ranking
- English, Urdu, Roman Urdu and Hindi options
- Four humor styles and intensity control
- Web UI, JSON API, tests and docs

## Planned
- Better multilingual quality evaluation and native-speaker review
- Anti-cliche and duplicate-output improvements
- Optional community example packs with provenance
- Docker deployment and hosted public demo

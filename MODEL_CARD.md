# COOKED model integration

COOKED is an application and prompt/style layer around an existing instruction-tuned model. Default local integration: Ollama with `qwen2.5:3b`.

This repository does not contain a foundation model trained from random initialization and does not claim the default model was trained by COOKED contributors.

Intended use: playful, consensual humor about fictional situations, ideas and captions. Quality varies by model, language and culture. Urdu, Roman Urdu and Hindi should be reviewed by fluent speakers. The lightweight input checks are not a complete moderation system.

The underlying model is downloaded separately and remains subject to its own license and terms.
